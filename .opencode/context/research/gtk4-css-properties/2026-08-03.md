# GTK CSS Properties

GTK supports CSS properties and shorthands as far as they can be applied in the context of widgets, and adds its own properties only when needed. All GTK-specific properties have a `-gtk` prefix.

## Basic Types

All properties support: `inherit`, `initial`, `unset`.

### Supported Units

| Type | Units |
|------|-------|
| Length | px, pt, em, ex, rem, pc, in, cm, mm |
| Percentage | % |
| Angle | deg, rad, grad, turn |
| Time | s, ms |

- `em`/`ex` resolved using font size (except on `font-size` itself, where inherited value is used)
- `rem` resolved using initial font size (not quite CSS standard)
- Physical units (pt, pc, in, cm, mm) translated to px using `-gtk-dpi` (not fixed 96dpi)
- `calc()` supported across all datatypes

### Four-Sides Shorthand Pattern

- 4 values: top right bottom left
- 3 values: top horizontal bottom
- 2 values: vertical horizontal
- 1 value: all

## Custom Properties (since 4.16)

```css
--prop: red;
color: var(--prop);
color: var(--prop, green); /* with fallback */
```

## Colors

### CSS Colors (supported)

- `rgb()`, `rgba()`, `hsl()` (legacy and modern syntax)
- `hwb()`, `oklab()`, `oklch()`, `color()`, `color-mix()`
- Relative colors
- `calc()` in color expressions

### Non-CSS Colors (deprecated — use custom properties instead)

**`@define-color` rules:**
```css
@define-color name color
/* Usage: @name */
```

**Color expressions (nestable):**
- `lighter(color)` — brighter variant
- `darker(color)` — darker variant
- `shade(color, number)` — lightness change (0=black, 2=white)
- `alpha(color, number)` — multiply alpha by number (0-1)
- `mix(color1, color2, number)` — interpolate between two colors

## Images

- `-gtk-icontheme(name)` — load themed icon
- `-gtk-recolor(uri, palette)` — recolor non-theme images
- `-gtk-scaled(image1, image2)` — hi-resolution display support

### Icon Palette

Symbolic icons recolored via `-gtk-icon-palette`. Recognized names: `error`, `warning`, `success`. Default palette maps to `error_color`, `warning_color`, `success_color`.

```css
-gtk-icon-palette: success blue, warning #fc3, error magenta;
```

## Media Queries (since 4.20)

Supports `not`, `and`, `or` expressions.

| Media Feature | Spec | Values |
|---------------|------|--------|
| `prefers-color-scheme` | Media Queries Level 5 | `light`, `dark` |
| `prefers-contrast` | Media Queries Level 5 | `no-preference`, `more`, `less` |
| `prefers-reduced-motion` | Media Queries Level 5 | `no-preference`, `reduced` |
