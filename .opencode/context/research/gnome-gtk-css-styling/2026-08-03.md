# CSS Styling in GTK

GTK uses CSS (Cascading Style Sheets) as its primary styling language, adapted for GUI applications. The system is built around a DOM-like tree of `GtkCssNode` objects which represent widgets and their sub-components. Styles are loaded via `GtkCssProvider` and resolved into `GtkCssStyle` objects that hold computed values for every property.

## CSS Styling Architecture

The architecture separates the loading of stylesheets from the resolution of styles for specific widgets.

### Data Flow: From CSS File to Computed Values

1. **Loading**: `GtkCssProvider` loads CSS data from files or resources
2. **Parsing**: The `GtkCssParser` consumes tokens from the `GtkCssTokenizer` to build `GtkCssRuleset` structures
3. **Selector Tree**: Rulesets are indexed into a `GtkCssSelectorTree` for efficient matching against widget nodes
4. **Matching**: When a `GtkCssNode` is invalidated it matches itself against the provider's selector tree to find applicable declarations
5. **Resolution**: Specified values are converted to computed values in `GtkCssStaticStyle`
6. **Animation**: If transitions are defined, a `GtkCssAnimatedStyle` is created to interpolate values over time

## CSS Node Hierarchy

The `GtkCssNode` is the backbone of the styling system, replacing the older `GtkWidgetPath`.

| Class | Purpose | Implementation Detail |
|-------|---------|----------------------|
| `GtkCssNode` | Base class for all styleable elements | Manages state, name, id, and classes |
| `GtkCssWidgetNode` | Links a `GtkWidget` to the CSS tree | Forwards state changes from the widget to the style system |
| `GtkCssNodeDeclaration` | Internal representation of node attributes | Used for fast hashing and comparison of nodes |

### Node Tree and Invalidation

Nodes are organized in a tree structure. When a property like a class or state changes, the node is marked as invalid. This triggers a re-validation process where the node re-matches selectors and re-computes its style.

## Style Computation and Values

GTK implements a robust type system for CSS values, ensuring that units (px, em, %, etc.) are handled correctly during the computation phase.

### Value Types and Resolution

- **GtkCssNumberValue**: Handles numeric types and units. Supports complex math via `calc()`, `min()`, `max()`, and `clamp()`
- **GtkCssColorValue**: Manages colors, including symbolic names and functions like `mix()`, `shade()`, and `alpha()`
- **GtkCssStyle**: An abstract object holding a collection of values for all CSS properties, divided into groups (core, background, border, font, etc.)

## Theme Integration

GTK integrates system themes by loading specific CSS files during initialization.

### Theme Loading Logic

`GtkCssProvider` looks for themes in the following order:

1. `$XDG_CONFIG_HOME/gtk-4.0/gtk.css`
2. `XDG_DATA_HOME/themes/THEME/gtk-4.0/gtk.css`
3. System directories like `/usr/share/themes`

The `THEME` name is determined by the `GtkSettings:gtk-theme-name` property. GTK also handles dark variants based on `GtkSettings:gtk-application-prefer-dark-theme`.

### Global vs. Local Providers

- **Global**: Added via `gtk_style_context_add_provider_for_display()`. These affect all widgets on a specific `GdkDisplay`
- **Local**: Added to a specific `GtkStyleContext` (deprecated in GTK 4 in favor of node-based styling)

## Rendering Pipeline Integration

Once styles are computed, they are used by the rendering system to create `GskRenderNode`s.

1. **Snapshot**: During the widget snapshot cycle, `GtkSnapshot` is used to record drawing operations
2. **CSS Snapshotting**: Functions like `gtk_css_style_snapshot_background()` and `gtk_css_style_snapshot_border()` take a `GtkCssStyle` and a `GtkSnapshot` to append the appropriate render nodes
3. **Shadows**: `GtkCssShadowValue` provides specialized snapshot functions for outset and inset shadows

## Key Implementation Files

| File | Role |
|------|------|
| `gtk/gtkcssprovider.c` | Entry point for loading and parsing CSS files |
| `gtk/gtkcssnode.c` | Core logic for the CSS node tree and invalidation |
| `gtk/gtkcssstaticstyle.c` | Implementation of resolved, non-animated styles |
| `gtk/gtkcssstylepropertyimpl.c` | Registration and parsing logic for all CSS properties |
| `gtk/gtkcssselector.c` | CSS selector matching and tree optimization |
| `gtk/css/gtkcssparser.c` | Low-level CSS syntax parsing |
