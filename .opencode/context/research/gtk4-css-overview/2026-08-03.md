# CSS in GTK

This chapter describes how GTK uses CSS for styling and layout. It focuses on listing supported CSS features and differences between Web CSS and GTK.

## CSS Nodes

GTK applies style information found in style sheets by matching selectors against a tree of nodes. Each node has a name, a state, and possibly style classes. Children are linearly ordered.

Every widget has one or more CSS nodes, determining their name, state, style classes, and layout in the overall node tree.

### Example: CSS nodes of a GtkScale

```
scale[.fine-tune]
├── marks.top
│   ├── mark
│   └── mark
├── trough
│   ├── slider
│   ├── [highlight]
│   └── [fill]
└── marks.bottom
    ├── mark
    └── mark
```

## Selectors

Selectors work very similar to the way they do on the web. All widgets have one or more CSS nodes with element names and style classes. Style classes are prefixed with `.` (period). Widget names are used like IDs, prefixed with `#`.

### GTK CSS Selectors

| Pattern | Reference | Notes |
|---------|-----------|-------|
| `*` | CSS Selector Level 3 | Universal selector |
| `E` | CSS Selector Level 3 | Type selector |
| `E.class` | CSS Selector Level 3 | Class selector |
| `E#id` | CSS Selector Level 3 | ID selector |
| `E:nth-child(n)` | CSS Selector Level 3 | Structural pseudo |
| `E:nth-last-child(n)` | CSS Selector Level 3 | Structural pseudo |
| `E:first-child` | CSS Selector Level 3 | |
| `E:last-child` | CSS Selector Level 3 | |
| `E:only-child` | CSS Selector Level 3 | |
| `E:link, E:visited` | CSS Selector Level 3 | GTK_STATE_FLAG_LINK, GTK_STATE_FLAGS_VISITED |
| `E:active, E:hover, E:focus` | CSS Selector Level 3 | GTK_STATE_FLAG_ACTIVE, GTK_STATE_FLAG_PRELIGHT, GTK_STATE_FLAGS_FOCUSED |
| `E:focus-within` | CSS Selector Level 4 | Set on all ancestors of focus widget (unlike CSS) |
| `E:focus-visible` | CSS Selector Level 4 | Set on focus widget and all ancestors (unlike CSS) |
| `E:disabled` | CSS Selector Level 3 | GTK_STATE_FLAG_INSENSITIVE |
| `E:checked` | CSS Selector Level 3 | GTK_STATE_FLAG_CHECKED |
| `E:indeterminate` | CSS Selector Level 3 | GTK_STATE_FLAG_INCONSISTENT |
| `E:backdrop, E:selected` | GTK-specific | GTK_STATE_FLAG_BACKDROP, GTK_STATE_FLAG_SELECTED |
| `E:not(selector)` | CSS Selector Level 3 | Negation |
| `E:dir(ltr), E:dir(rtl)` | CSS Selector Level 4 | Direction |
| `E:drop(active)` | CSS Selector Level 4 | Drag-and-drop |
| `E:root` | CSS Selector Level 3 | |
| `E F` | CSS Selector Level 3 | Descendant combinator |
| `E > F` | CSS Selector Level 3 | Child combinator |
| `E ~ F` | CSS Selector Level 3 | General sibling combinator |
| `E + F` | CSS Selector Level 3 | Adjacent sibling combinator |
